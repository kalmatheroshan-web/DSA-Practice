## 💻 About This Repository

Welcome to my DSA practice repository!

This is where I build my problem-solving skills using **C++**, practice important algorithmic patterns, analyze time and space complexity, and work toward mastering Data Structures and Algorithms.

My goal is simple: **understand the logic, write the code, learn from mistakes, and improve every day.**

## 🎯 Learning Roadmap

- [ ] **Programming Fundamentals** — Complexity Analysis, Mathematics, Bit Manipulation
- [ ] **Arrays & Strings** — Basic Operations, Prefix Sums, Hashing
- [ ] **Searching & Sorting** — Binary Search, Sorting Algorithms
- [ ] **Problem-Solving Patterns** — Two Pointers, Sliding Window, Fast & Slow Pointers
- [ ] **Linear Data Structures** — Linked Lists, Stacks, Queues
- [ ] **Recursion & Backtracking** — Subsets, Permutations, Combinations
- [ ] **Trees & Binary Search Trees**
- [ ] **Heaps & Tries**
- [ ] **Graphs** — BFS, DFS, Topological Sorting, Union-Find
- [ ] **Greedy Algorithms**
- [ ] **Dynamic Programming**
- [ ] **Advanced Problem Solving & Revision**

*Progress is updated as I work through each topic.*

## 🧠 My Problem-Solving Workflow

```text
Understand the Problem
        ↓
Find the Brute-Force Approach
        ↓
Identify the DSA Pattern
        ↓
Optimize the Solution
        ↓
Test Edge Cases
        ↓
Analyze Time & Space Complexity
        ↓
Learn, Revise, Repeat
```

## 📌 My Rules

- Understand the approach before writing code.
- Never count a copied solution as a solved problem.
- Compare brute force with optimized solutions.
- Track mistakes and revisit difficult questions.
- Focus on consistency, not just the number of problems solved.
